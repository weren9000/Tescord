# KVA Chat для Android — 0.1.1, тестовая сборка

APK: `release/KvaChat-0.1.1-android.apk`, SHA-256 рядом. Android 10+ (API 29), один APK для телефонов ARM и эмуляторов x86. Установка напрямую, без Google Play. Интерфейс включён в APK, сервер — `https://kvachat.ru`. Обновления пока устанавливаются новым APK поверх старого.

В 0.1.1 обновлён интерфейс личных звонков: устранена блокировка устаревшим статусом друга, исправлен порядок подключения микрофона, добавлены рингтон и исходящие гудки. Включены настройки TURN. `versionCode=2`, подпись тем же ключом, что у 0.1.0. Перед `node prepare-web.cjs` задайте `KVA_NATIVE_RUNTIME_CONFIG` — путь к локальному JSON публичной конфигурации сайта, содержащему `iceServers`. Файл не хранится в Git. Проверка настоящих фоновых звонков на Android по-прежнему требует телефона.

## Реализовано

- Capacitor 8.5.3 и существующий Angular-интерфейс; приложение открывается без адресной строки браузера.
- Вход хранится зашифрованным AES-GCM с ключом Android Keystore. Резервное копирование сессии и перенос на другое устройство отключены.
- Foreground service держит два авторизованных WebSocket-соединения: события сообщений и входящие личные звонки. Firebase и Google-аккаунт не нужны. Уведомления сообщений учитывают настройку конкретной беседы. Нажатие открывает беседу или входящий звонок.
- Постоянное уведомление позволяет остановить службу. Повторное открытие приложения после входа включает её снова. Выход из аккаунта останавливает службу и демонстрацию. После принудительной остановки приложения уведомлений не будет до следующего запуска. Автозапуск после перезагрузки телефона пока не добавлен.
- Системные разрешения на микрофон, камеру, уведомления; после входа предлагается исключение из оптимизации батареи. Служба объявляет используемые микрофон/камеру и держит wake lock во время захвата медиа.
- Демонстрация через Android MediaProjection с обязательным системным подтверждением. Кадры передаются в canvas/WebRTC: до 960 px по длинной стороне, до 8 кадров/с, без системного аудио. Это начальная реализация для показа интерфейса, не для трансляции игр. Остановка доступна в приложении и системном уведомлении.
- Системные панели и клавиатура учитываются Capacitor; внешние ссылки открываются вне WebView. Сторонние iframe запрещены.

## Проверено / ограничения

2026-10-16: production-сборка Angular; Gradle `assembleRelease` и `lintDebug` — успешно (0 ошибок, 24 предупреждения, в том числе зависимости/шаблонные ресурсы и ожидаемое предупреждение о запросе исключения батареи). Подпись APK проверена `apksigner` (v3, Android 10+).

`node web-smoke.cjs` проверяет собранный экран входа при ширине 393 px, JS-мост с имитацией native API, доступ к production API с Android origin, отмену захвата и повторную попытку. Это **не проверка настоящего Android runtime**.

Подключённых физических телефонов нет. Эмулятор API 35 без аппаратной виртуализации остался offline, приложение на нём не запускалось. Уведомления при блокировке/смене сети, продолжение разговора в фоне, Bluetooth, камера и реальная демонстрация на телефоне **ещё не проверены**. WebView и ограничения производителя могут влиять на фоновые медиа. Не считать эту сборку подтверждённым стабильным релизом.

Проверка на устройстве: разрешить уведомления и фоновую работу; войти; включить уведомления нужной беседы; получить сообщение и звонок при открытом приложении, после сворачивания и после блокировки на 15 минут; открыть уведомление; проверить звук в обе стороны, камеру, демонстрацию и её остановку; переключить Wi-Fi/мобильную сеть; проверить выход из аккаунта. На Android 13+ отдельно проверить отказ и последующее включение разрешения уведомлений.

## Сборка

Нужны Node.js, Java 21, Android SDK Platform 36 и Build Tools 36.0.0. В `android/local.properties` указать SDK (`sdk.dir=D\:/.../sdk` на Windows). Файл локальный, в Git не входит.

```powershell
cd frontend
npm ci
npm run build
cd ../mobile
npm ci
node prepare-web.cjs
npm run sync
cd android
./gradlew.bat assembleRelease lintDebug --console=plain
cd ..
./sign-release.ps1 -SdkRoot D:/Code/Kva/android-tools/sdk -SigningDirectory D:/Code/Kva/android-signing
node web-smoke.cjs
```

Для web-smoke используются Playwright из `desktop/node_modules` и Chromium; путь можно задать через `KVA_CHROME`.

Ключ текущего выпуска: `D:/Code/Kva/android-signing/kvachat-android.p12`; пароль в `password.txt` там же. Каталог доступен текущему Windows-пользователю и SYSTEM, находится **вне Git**. Сохранить его отдельную защищённую резервную копию: другой ключ не позволит обновить установленное приложение с сохранением данных. Скрипт подписи никогда не создаёт замену ключу автоматически.

В production `TESCORD_CORS_ORIGINS` дополнен ровно `https://localhost` для локального интерфейса APK. Предыдущее значение сохранено в `/srv/tescord/shared/backend.env.before-android`. API по-прежнему требует токен; TLS и проверка WebSocket origin не отключены. При переносе сервера сохранить этот origin.
