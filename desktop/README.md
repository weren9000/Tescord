# Квачат для Windows — 0.3.0

Выпуск 0.3.0 добавляет нативные уведомления Windows о сообщениях и входящих личных звонках. Они работают при запущенном клиенте, включая сворачивание в трей; после полного выхода доставка не выполняется. Сообщения требуют включения уведомлений в соответствующей беседе. Общий выключатель «Уведомления» находится в меню трея и сохраняется между запусками. В активном окне всплывающие уведомления подавляются, одинаковые события не повторяются. Нажатие открывает беседу либо входящий звонок без автоматического ответа. Выход из аккаунта закрывает уведомления.

Установщик: `desktop/release/KvaChat-Setup-0.3.0-x64.exe`, контрольная сумма рядом в `.exe.sha256`. Подписи издателя пока нет. Проверки `notifications-smoke.cjs` и `message-notifications-smoke.cjs` выполняются на Windows 11: нативный API, подавление дублей, обработчик нажатия, общий выключатель, реальные сообщения локального сервера в открытой и другой беседе, отключение отдельной беседы. Программно вызывается событие нажатия; отдельной проверки Центра уведомлений Windows 10 нет. Windows может скрывать баннеры согласно системным настройкам уведомлений.

Для надёжной доставки событий требуется серверное исправление сериализации дат в `app_events.py`, включённое в этот выпуск. Без него события прочтения могли разрывать WebSocket.

Выпуск 0.2.0: актуальный интерфейс чата и ВКС, настройки устройств и индивидуальная громкость участников, логотип KVA в установщике, окне и трее. Установщик не содержит пользовательских сессий и тестовых данных. Обновление сохраняет локальный профиль существующей установки.

Артефакты: `desktop/release/KvaChat-Setup-0.2.0-x64.exe` и файл `.exe.sha256`. Выпуск не подписан цифровой подписью издателя.

Проверено для 0.2.0 на Windows 11: обновление с 0.1.0, удаление, чистая установка, запуск установленного клиента с отдельным пустым профилем, production API, шифрование сессии, выбор источника демонстрации и сворачивание в трей. `KVA_TEST_FIXTURE=... node desktop/scripts/conference-smoke.cjs` проверяет два Electron-клиента на локальном сервере: вход, приём звука и видео, демонстрацию окна, настройки устройств и доступность индивидуальной громкости. Отдельного прогона на Windows 10 и физических гарнитурах нет.

Тестовый клиент для Windows 10 22H2 / Windows 11 x64. Angular-интерфейс включён в установщик; API и LiveKit используют существующий сервер https://kvachat.ru. Отдельный браузер не требуется, подключение к интернету требуется.

## Сборка

На Windows с Node.js 22.12+:

```powershell
npm ci --prefix frontend
npm run build --prefix frontend
npm ci --prefix desktop
npm run dist --prefix desktop
```

Установщик: `desktop/release/KvaChat-Setup-0.2.0-x64.exe`. NSIS устанавливает приложение для текущего пользователя; доступны выбор папки, ярлыки и штатное удаление Windows. Автообновлений пока нет. Для следующего выпуска нужно собрать новый установщик. Не отключайте проверку TLS или изоляцию интерфейса.

## Поведение

- Аккаунты и данные общие с сайтом. Веб-интерфейс на сервере обновлять для выпуска клиента не требуется.
- Размер и положение окна сохраняются. Повторный запуск активирует уже открытое окно.
- Закрытие окна сворачивает приложение в трей; меню трея → «Выйти» завершает работу и звонки.
- Сессия хранится отдельно от браузера, в `session.bin` через Electron safeStorage / Windows DPAPI. Выход из аккаунта удаляет её. Пароль отдельно не сохраняется.
- Источник демонстрации выбирается явно. Системный звук, если включён, относится ко всему компьютеру, а не только выбранному окну.
- UI работает с `sandbox`, `contextIsolation`, отключённым Node.js. IPC сессии разрешён только главному окну; выбор захвата — только окну выбора.

Не входят в 0.1.0: автообновления, автозапуск, глобальные горячие клавиши, системная регистрация ссылок kvachat://, отдельная интеграция фоновых push-уведомлений. Первое завершение этой версии не заявляет поддержку уведомлений при полностью закрытом приложении.

## Проверка

`node desktop/scripts/smoke.cjs` запускает реальный Electron с отдельным временным профилем: локальная сборка UI, API production, отсутствие Node.js в интерфейсе, шифрование/удаление сессии, выбор и отмена захвата, закрытие в трей.

Для проверки установленного клиента задаётся `KVA_SMOKE_EXE` с абсолютным путём к exe. Использовать только пустой профиль; тест отказывается перезаписывать существующую сессию. Диалог разрешений в автоматическом тесте подтверждается программно.

`KVA_TEST_FIXTURE` указывает локальную фикстуру для `node desktop/scripts/integration.cjs`. Два экземпляра подключаются к локальному Angular на localhost:4200, проверяют вход, двусторонний LiveKit-звук, передачу окна, восстановление зашифрованной сессии после перезапуска и выход. Никакие тестовые аккаунты не создаются на production. Переменные `KVA_DESKTOP_TEST*` не действуют в упакованной версии.

Проверено на Windows 11 (build 26100): сборка NSIS, установка, запуск установленного приложения, production API, локальный интеграционный сценарий с двумя клиентами. Отдельной машины Windows 10 в этой среде нет; прогон на Windows 10, физические Bluetooth-гарнитуры и качество системного аудио остаются ручной проверкой.
