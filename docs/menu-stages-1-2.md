# Меню: аудит и первый релиз, 14 октября 2026

Объём: этапы 1–2 из плана перестройки меню — аудит и общая поверхность действий для чата и личного меню. Нумерованные разделы 1–10 исходного предложения не являются этапами релиза.

## Карта существующих функций и прав

| Область | Уже реализовано | Решение первого релиза |
|---|---|---|
| Навигация | Друзья, группы, площадки; события; мобильная нижняя панель | Сохранить разделы. Аватар открывает личное меню. Инвентарь перенесён в личное меню, админка остаётся под площадками |
| Закрепление | `PUT /api/conversations/{id}/pin`, личный флаг членства, `pinPending` | Использовать существующий обработчик, показывать сохранение и ошибку в меню |
| Уведомления | Личный `push_enabled`, BrowserPushService и `/api/push/conversations/{id}/setting` | Использовать текущую подписку/отключение, блокировать повторный запрос и показывать результат внутри меню |
| Обои | WallpapersComponent: профиль, личная замена и общий фон; права проверяются API | Открывать существующий выбор из чата и личного меню, без второго каталога |
| Материалы | Поиск и файлы чата | Файлы доступны в группе «Материалы»; поиск остаётся кнопкой шапки. Отдельного работающего списка закреплённых сообщений нет — пункт не добавлен |
| Управление группой | Участники, добавление, ссылки приглашения | Участники доступны членам; управление — владельцу, администратору пространства или системному администратору согласно существующим проверкам |
| Площадки | Настройки также доступны владельцу голосового канала в его области полномочий | Сохранить существующий `canOpenPlatformSettings`, не расширять права |
| Завершение участия | Выход/блокировка, передача владения для владельца | Отделить нижней группой; подтверждать выход участника и удаление/блокировку друга; сохранить процедуру передачи владения |
| Профиль и предметы | Редактор, InventoryComponent, роли `is_avatar_admin` и `is_admin` | Личное меню: профиль, инвентарь, внешний вид, звук, настройки, выход; административные действия видны только соответствующим ролям |
| Память переписки | WorkspaceMemoryService сохраняет черновик, канал, якорь сообщения и смещение | Меню не размонтирует переписку и не переключает беседу |

## Общий компонент

`ActionMenuComponent` использует нативный modal dialog в верхнем слое браузера. На ПК меню привязано к кнопке и ограничено границами окна; до 980 px — нижняя панель с собственной прокруткой и безопасным отступом. Закрытие: кнопка, фон, Esc. Стрелки/Home/End перемещают фокус, Tab/Shift+Tab удерживают его внутри. После закрытия фокус возвращается без прокрутки страницы. При открытии следующего нативного диалога фокус у него не отбирается.

Темы используют существующие palette-переменные. Компонент не делает API-запросы: действия и проверки прав остаются в AppComponent и backend.

## Остальные этапы и границы

- Перестройка списка, дополнительные фильтры, меню строк и долгие нажатия ещё не перенесены на новый компонент.
- Информационная панель беседы и разделение меню площадки/канала — следующий этап.
- Инвентарь, каталог админки и звонок сохраняют прежние интерфейсы.
- Настройки пока объединяют ссылки на работающие экраны; нового общего центра уведомлений и безопасности аккаунта нет.
- «Обои» в личном меню открывают существующий выбор: при открытой беседе он также предлагает её контекст; область изменения явно выбирается в нём.

## Проверки

Проверять владельца и обычного участника, ширины 1440/390/844 px, светлую и тёмную палитры, возврат фокуса и отсутствие горизонтального переполнения. Проверять закрепление и отключение уведомлений с чтением результата через API; ошибку закрепления — с временным ответом 503; переходы к профилю и обоям — с сохранением текущей беседы. Регрессионные проверки клавиатуры и фона находятся в `action-menu.component.spec.ts`.

Выполнено: production build; 22/22 Karma/ChromeHeadless теста; Playwright на локальном API и тестовой БД для владельца и участника, 12 сочетаний экрана/палитры, мобильное личное меню, отмена выхода участника. Ошибок JavaScript нет. Палитры взяты из серверного `themes.py` и применены в браузере без изменения инвентаря. Артефакты локального прогона: `D:/Code/Kva/menu-review/`.

Ограничения проверки: мобильные размеры эмулировались в Chromium, физические устройства и Safari не проверялись. Сохранение закрепления и отключение push подтверждены API; доставку push и выдачу браузерного разрешения этот релиз не меняет и не проверяет.
