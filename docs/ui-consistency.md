# Общие стили интерфейса

Размеры и типографика находятся в `frontend/src/_ui-tokens.scss`, общие SCSS-mixins — в `frontend/src/app/shared/_ui-controls.scss`.

- Основные кнопки и поля: минимум 44 px; вход и присоединение: 48 px.
- Кнопка с иконкой: 44 × 44 px, иконка 20 px. Компактные действия участника: 36 px, на сенсорном устройстве — 44 px.
- Основной текст: 14 px, вторичный: 12 px, заголовок панели: 18 px. Поля на телефоне: 16 px.
- Отступы: 4, 8, 12, 16, 24, 32 px. Скругления: 8 px у элементов управления, 12 px у панелей, 16 px у диалогов.
- Цвета берутся из `--palette-*`; не добавлять фиксированный тёмный фон в общие компоненты. Проверять светлые и пользовательские темы.
- Клавиатурный фокус должен оставаться видимым. У кнопок без подписи нужны `aria-label` и понятное активное состояние.

Для рабочего пространства общие правила собраны в `_workspace-ui.scss`, для магазина и инвентаря — в `_catalog-ui.scss`. Комната и авторизация подключают mixins непосредственно в свои стили.

В личном звонке индивидуальная громкость открывается через кнопку «Участники». В группе и комнате ползунок находится в строке человека. Общего ползунка громкости нет. Панель участников должна помещаться в экран целиком, включая кнопку закрытия и значение громкости.

Проверки: `npm run lint`, `npm run format:check`, `npm run test:ui`, `npm run build` из `frontend`. UI-тесты используют локальные данные; аудиотест измеряет реальный PCM-сигнал. Дополнительно просматривать снимки профиля, звонков и комнат на 320–393 px и настольной ширине.
