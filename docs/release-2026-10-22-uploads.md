# Загрузка вложений и клиенты 2026-10-22

Windows 0.5.13, Android 0.3.16 (versionCode 20).

В сообщении доступно до 10 вложений. Клиент проверяет количество до загрузки,
передаёт файлы тремя параллельными запросами и публикует сообщение после их
готовности. Повтор сохраняет готовые вложения и идентификатор сообщения.
Добавлены прогресс отдельных файлов, пауза, отмена, отправка готовых вложений,
компактные превью и отдельный список для ПК и телефона. Переход между чатами
сохраняет активную очередь; перезагрузка приложения очередь не восстанавливает.

Миграция 20261022_0051 добавляет временные загрузки и порядок вложений.
Неопубликованные загрузки учитываются в квоте и истекают через 24 часа.
Старый API отправки файлов сохранён для предыдущих клиентов.

Проверки: 96 frontend-тестов, серверный сценарий загрузки/повтора/прав/истечения,
14 регрессионных серверных тестов, браузерный сценарий 1/5/10/11 файлов,
сбой одного файла, повтор, навигация, отправка готовых и отмена.
Production web build и Android assembleRelease/lintDebug проходят.
Проверены упакованный EXE, Android web bridge, доступ к production API,
изоляция/хранение сессии Windows, отмена выбора демонстрации и мобильная ширина.
Физическое Android-устройство в этой проверке не использовалось.

APK подписан существующим ключом. EXE остаётся без подписи издателя.
Артефакты и SHA-256 публикуются по версионным ссылкам /downloads/.
