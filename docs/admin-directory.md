# Административный каталог — первый выпуск

Кнопка «Админка» доступна системным администраторам в левой панели и меню приложения. Роль администратора аватарок не предоставляет этот доступ. Раздел содержит пользователей, группы и площадки, серверный поиск и сортировку, фильтры ролей/владельца, страницы по 24 или 48 записей. Фильтры и положение списка сохраняются при смене вкладок. Подробности открываются справа, на телефоне — на весь экран.

API `/api/admin/directory` проверяет `User.is_admin` на каждом запросе, выдаёт `Cache-Control: no-store`, выбирает только необходимые поля. Email доступен в подробностях пользователя. Пароли, сессии, токены, переписка и прямые диалоги не выдаются. Связанные списки участников, каналов и пространств пользователя имеют собственную пагинацию. Поля поиска экранируют SQL wildcard-символы; порядок выдачи стабилизирован ID.

Пользовательские аватары и загруженные иконки поддерживают `preview=true`: статический WebP до 96×96, кеш по хешу исходника, атомарная запись. Эти миниатюры показывают аватар без декоративной рамки. Оригиналы и обычные URL не изменены. При ошибке картинки карточка показывает инициалы.

В этой версии нет изменения ролей, блокировки и удаления. В текущей модели нет глобального состояния блокировки аккаунта, поэтому соответствующий статус и фильтр не имитируются. Списки каналов показывают название и тип; управление доступом и приглашениями остаётся отдельной задачей. Новых миграций БД нет.

Проверено: 32 frontend-теста; 5 backend-тестов каталога и превью; production build. Браузер на 1440×1000, 1280×720, 390×844 и 320×740: вкладки, подробности, поиск, пустой результат, сохранение фильтра, ошибка/повтор, закрытие при 403, вход из мобильного меню и отсутствие горизонтальной прокрутки. Материалы: `D:/Code/Kva/admin-directory-review/`. Сохраняется прежнее предупреждение о размере основного SCSS.
