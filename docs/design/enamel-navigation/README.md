# Навигация «Значки на эмали»

Согласованный эскиз — `reference.png`. Прозрачный мастер `master.png` сохраняет девять выбранных образов и добавляет мобильное меню с тремя золотыми полосками. Генерация: встроенный ImageGen, точный промпт и происхождение — `generation.json`.

Экспорт из `frontend`: `node scripts/prepare-enamel-navigation.cjs`. Скрипт разделяет мастер, нормализует прозрачные поля и создаёт WebP 128/256/512 px в `frontend/public/assets/enamel-navigation/`. Альфа-канал сохраняется. Границы ячеек относятся к этому мастеру; при его замене нужно повторно проверить все кадры.

Подключение: `section-navigation.component.ts` (36 px), нижняя панель в `app.component.html` (34 px), соответствующие пункты меню приложения (32 px). Функции кнопок, доступные имена и индикаторы не меняются. Компактные функциональные SVG и графика остальных экранов используют прежний набор.

Проверка: `npm run test:ui -- navigation-art.spec.ts`. Сценарий проверяет ширины 320/393/1024/1440, загрузку мобильных изображений, переключение группы, меню и Escape; сохраняет снимки тёмной и светлой палитр в `frontend/test-results/`.

Меню приложения дополнено шестью значками: профиль, оформление, звук, блокировки, выход и установка. Мастер — `menu-master.png`, происхождение — `menu-generation.json`, экспорт — `node scripts/prepare-enamel-menu.cjs`. Поверхность меню использует общий материал «Парящая панель»; на телефоне сохраняется отступ от края, а список прокручивается отдельно от баланса и заголовка. Проверка также покрывает низкий экран 320×560 и возврат фокуса после Escape.
