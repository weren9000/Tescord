# Набор и карта перехода

Этап: общая библиотека подключена к приложению. Реализованные области и результаты проверок — `application-rollout.md`. Логотип — «Лунный свет», художественный эталон кнопок — painted-controls/reference.png.

## Покрытие и границы

Набор: 76 компактных SVG, 20 рисованных изображений (8 новых), существующие 8 текстур кнопок/панели. Закрыты все 55 ключей старого UiIconComponent и дополнительные значки vacation/star/location календаря. Имена совместимы, но геометрия переработана. Количество имён не равно количеству уникальных действий.

Воспроизводимая карта `inventory.json` содержит объявления из frontend/src/app, двух дополнительных приложений и desktop/ui. В ней отмечены динамические выражения и их источники, встроенные SVG, текстовые действия и нативные брендовые изображения. Сканирование исходников не исполняет Angular-условия и не гарантирует видимость элемента пользователю; перед заменой проверяется реальный контекст и роль пользователя. Объявления одного элемента в цикле считаются одним местом.

## Правила соответствия

| Текущее место | Новый элемент | Условие |
| --- | --- | --- |
| UiIconComponent, статическое имя | PaintedGlyphComponent с тем же именем | Сверить размер, контраст и семантику |
| Динамические mic/micOff, camera/cameraOff, sound/soundOff | Те же пары нового набора | Сохранять изменение знака и доступного названия |
| «Приложения» в section-navigation | applications вместо inventory | Предметы сохраняют inventory |
| Каталог дополнительных приложений | Собственная обложка приложения | Не заменять игровые ресурсы и иллюстрации |
| Комната, друзья, группы, площадки | Готовые крупные рисунки либо компактные SVG | Рисунок от 48 px, SVG в плотной панели |
| Крупные предметы, магазин, подарок, профиль, оформление | Новые рисованные WebP | Подпись остаётся текстом |
| Безопасность | security для крупной иллюстрации; lock/avatarAdmin в управлении | Различать защиту и административную роль |
| Настройки звонка | callSettings (ползунки) | Общие настройки сохраняют settings |
| Календарь, отпуск, место, избранное | calendar, vacation, location, star | Экспорт SVG/CSS без зависимости от Angular |
| Встроенные SVG | Проверка каждого назначения по месту | Не заменять графики статистики и игровую геометрию |
| Пользовательские эмодзи, аватары, обои, изображения групп | Сохраняются | Это пользовательский контент, а не устаревший UI |
| Скрытые секретные чаты | Не активировать | Наличие исходников не разрешает возвращать интерфейс |
| Windows/Android, favicon и splash | Отдельный выпуск платформенных ресурсов | Готовый исходник логотипа уже есть; нужна проверка масок, размеров, прозрачности и установщиков |

## Текстовые действия

| Экран | Решение для следующего этапа |
| --- | --- |
| text-file-viewer | ✕ → close; копировать/скачать → компактные кнопки с подсказками; перенос строк → wrap с aria-pressed; «Документ / Исходный текст» оставить подписанным переключателем |
| photo-viewer | Стрелки и символы масштаба → back/forward/zoomIn/zoomOut; процент масштаба оставить текстом |
| message-actions | reply/edit/copy/eye/download/trash нового набора; эмодзи реакций сохраняются |
| upload-panel | Кнопки отмены, повтора, удаления и загрузки из нового набора, прогресс остаётся явным |
| section-navigation | Крупные рисунки при достаточной ширине либо SVG с подписями; разные знаки приложений и предметов |
| auth-page/account-security | Войти, зарегистрироваться, подтвердить почту, включить/выключить 2FA — явные текстовые кнопки |
| wallet/shop | Подтвердить перевод, стоимость, покупка, удаление — понятные подписи; не скрывать смысл в одиночной иконке |
| admin-directory и массовые действия | Явная подпись, количество объектов, состояние загрузки и результат |
| Ссылки на страницы и скачивания | Сохранить href, открытие в новой вкладке и браузерные действия; применять общий внешний вид отдельно |

Не превращать пояснения, заголовки и статусы в кнопки. Для действий без подписи обязательны aria-label, клавиатурный фокус и подсказка; мобильный экран не должен зависеть от hover.

## Последовательность подключения

1. Навигация и общие меню.
2. Сообщения, документы, загрузки и просмотр фотографий.
3. Звонки, комнаты, группы и площадки.
4. Профиль, авторизация и безопасность.
5. Инвентарь, магазин и кошелёк.
6. Администрирование.
7. Дополнительные приложения и оболочки.

Для каждого раздела: текущий снимок, замена в ограниченном компоненте, сравнение после изменения; светлая/тёмная темы, 320–393 px и настольный экран, длинные подписи, disabled/loading/error, клавиатура и reduced-motion. Звонки проверяются реальным входом/повторным входом/демонстрацией/выходом; изменение звука — аудиосигналом. Нативные окна и упаковка проверяются отдельными сборками. Выполненные локальные проверки и ограничения текущего перехода перечислены в `application-rollout.md`.

## Экспорт и проверка

Из frontend: `node scripts/audit-ui-kit.cjs`, `node scripts/prepare-painted-assets.cjs` (если менялись мастера), `node scripts/build-painted-kit.cjs`, `node scripts/check-painted-kit.cjs`.

Каталог: artifacts/painted-controls/index.html. Внутри настоящие Angular-компоненты, поиск по SVG, сравнение старых/новых знаков, 16/20/24/32/48 px, светлый и тёмный примеры, управление сообщением/документом/меню/разделами. Отдельные SVG и sprite.svg, CSS, WebP и Angular-исходники лежат рядом. Код генератора изображений не требуется приложению; PNG-мастера не загружаются на страницу.
