# Подключение нового оформления к приложению

## Что изменено

- UiIconComponent сохраняет прежний интерфейс, но рисует общие PAINTED_GLYPHS. Навигация использует готовые рисованные изображения с текстовыми подписями, логотип — «Лунный свет».
- `_cosmic-application.scss` задаёт палитру по умолчанию, оформление кнопок, форм, диалогов и панели звонка. Пользовательская тема продолжает управлять цветовыми переменными; пользовательские обои и аватары не заменяются.
- Локальная геометрия кнопок сообщений, документов, фотографий и звонков заменена общими значками. Кнопки копирования, скачивания, масштаба и закрытия сохраняют доступные названия. Просмотр документа поддерживает перенос строк, исходный текст, загрузку и ошибки.
- Экспорт статусов сохраняет старые URL микрофона и уведомлений, чтобы не менять логику звонка. Выключение, блокировка и активный звук остаются разными состояниями.
- Общие стили применяются также к авторизации, профилю, настройкам, каталогу, кошельку и административным формам. Это не изменение их прав или бизнес-логики.
- Календарь получает локальный экспорт SVG и фактур; «Острова» — оформление управления с сохранением игровых иллюстраций. Оба приложения остаются независимыми от Angular.
- Windows получает оформление выбора экрана. Web/favicon и Android launcher/splash используют утверждённый логотип. Значок Android-уведомления монохромный, как требует системная панель.

## Воспроизведение

Из `frontend`:

```text
node scripts/export-status-glyphs.cjs
node scripts/export-plugin-controls.cjs
node scripts/export-application-brand.cjs
node scripts/build-painted-kit.cjs
node scripts/check-painted-kit.cjs
npm run lint
npm run format:check
npm run build
npm run test:ui -- shared-navigation.spec.ts platform-navigation.spec.ts call-chat.spec.ts auth-security.spec.ts message-editing.spec.ts applications.spec.ts existing-ui.spec.ts islands.spec.ts landing-news.spec.ts
```

Экспорт платформенной графики требует локального утверждённого PNG-мастера и Chromium. Обычная сборка приложения использует уже подготовленные ресурсы.

## Проверки

Основная серия: 42 из 42 локальных UI-сценариев прошли. Проверены 320/393/1024/1440 px, светлая и тёмная темы, формы входа/почты/2FA, каталог приложений, меню, навигация, сохранение черновиков, редактирование сообщений и ошибки. Проверки комнаты охватывают 1/2/6/50 участников, демонстрацию, панель участников и мобильную клавиатуру. Проверка индивидуальной громкости использует действительный PCM-сигнал в локальной тестовой среде.

Каталог компонентов отдельно проверяет клавиатуру, disabled/loading, форму, переключатели, отсутствие горизонтального переполнения и системные режимы reduced-motion/forced-colors. Сборка frontend и подготовка Windows web-оболочки проходят. Форматирование: без новых ошибок; lint: без ошибок, осталось прежнее предупреждение OnInit в store-collections.

Дополнительно прошли браузерные проверки календаря (320–1536 px) и игрового поля «Островов» (320/393/768/1440 px). Gradle `:app:processDebugResources` успешно проверил ресурсы Android после Capacitor sync. В отдельной локальной проверке документа проверены переключение исходника, перенос строк, запись в буфер обмена, скачивание и Escape на 320/393/1440 px; в окне Windows — выбор экрана и отмена с тестовым bridge.

Просмотрены снимки формы 2FA на 320 px, чата и навигации на 393 px, группового звонка на 1440 px, комнаты с шестью участниками на 393 px, светлого каталога, документа, календаря и окна выбора экрана Windows. Галерея: `artifacts/application-design/index.html`.

Просмотр фотографий дополнительно проверен на 320 px: загрузка, масштаб, переход к следующему изображению и Escape. Android Emulator не запускался и не оставлен работающим.

Это локальная проверка интерфейса с тестовыми данными. Она не заменяет проверку реального многопользовательского звонка через LiveKit и установку подписанных APK/EXE на устройства. Релиз не опубликован; версии приложений не повышались.
