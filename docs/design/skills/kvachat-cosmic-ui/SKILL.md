# Космическая компания — интерфейс

В checkout Tescord прочитай `docs/design/cosmic-friends.md` и открой `docs/design/reference.png`. Это выбранный эталон, а не предложение нового стиля. При отсутствии checkout используй копию `references/cosmic-friends.md`.

Сохраняй сцену общения и ясность продукта: текст/действия отдельно от иллюстрации, реальные компоненты поверх художественного окружения. Для новых рисованных кнопок и иконок прочитай `docs/design/painted-controls/README.md` (либо `references/painted-controls.md`) и просмотри `docs/design/painted-controls/reference.png`: этот вариант 09 заменил «Лунную эмаль». Используй готовые PaintedButtonComponent, PaintedGlyphComponent и PaintedArtComponent из `frontend/src/app/shared/painted-controls/`. Крупные иконки — рисованные, компактные — SVG; маленькие управляющие знаки должны читаться. Каталог `artifacts/painted-controls/index.html` использует реальные компоненты. Палитра scoped к изменяемой области; не перекрашивай всё приложение без запроса. Старые экраны сохраняют UiIconComponent до отдельной задачи.

Для публичной страницы держи регистрацию и вход один раз, скачивания непосредственно под ними. Не возвращай удалённые новости и вторую панель скачивания. На mobile лицо персонажа, CTA и текст должны оставаться читаемыми.

Следуй `kvachat-ui` для реализации и проверки. Проверяй выбранный экран по эталону, а не только по успешной сборке. Новое оформление не является разрешением на деплой или изменение других разделов.
