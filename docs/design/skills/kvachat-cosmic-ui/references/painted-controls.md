# Квачат — рисованные иконки и кнопки

Текущий эталон — `reference.png` рядом с этим документом: вариант 09 «В стиле космической компании». Он заменяет прежнее направление «Лунная эмаль» для иконок и кнопок. Это отдельный набор для подключения к интерфейсу; текущие экраны приложения автоматически не заменяются.

## Что входит

- 20 рисованных иконок: базовые 12 и новые приложения, предметы, магазин, подарок, оформление, профиль, безопасность и календарь. Прозрачные WebP в 128, 256 и 512 px. Новые мастера и промпты перечислены в `expansion-generation.json`.
- 72 компактных SVG: покрыты все 55 имён UiIconComponent, календарь и дополнительные действия. Индивидуальные файлы и SVG-спрайт экспортируются в каталог.
- 8 поверхностей: основная, вторичная, опасная и нажатая прямоугольные кнопки; обычная, активная и опасная круглые кнопки; панель.
- Angular-компоненты `PaintedButtonComponent`, `PaintedGlyphComponent`, `PaintedArtComponent`. Каталог использует именно эти компоненты.

## Художественные правила

Фиолетовая краска с заметными мазками, тёплый золотистый свет сверху слева, локальное бирюзовое отражение снизу. Тени сливовые. Края сохраняют лёгкую рисованную неровность. Избегать гладкого пластика и замены фактуры CSS-градиентом. Текст кремовый, без свечения.

Для крупных карточек и меню использовать рисованные изображения с размером от 48 px. Для плотного управления и кнопок — компактные SVG, обычно 24 px. Не уменьшать лица и многослойные рисунки до 16 px. Существующие экраны сохраняют свой набор иконок до отдельной задачи на оформление.

Кнопки — настоящие HTML button. Надписи и знаки не запекаются в текстуру. Края прямоугольных текстур масштабируются отдельно от центра через border-image. Минимальная высота 44 px, обычная 52 px, большая 64 px. Длинный текст может переноситься. Размер кликабельной области сохраняется при загрузке. Красный предназначен для завершения и опасного действия.

Состояния: hover усиливает свет; pressed использует отдельную вдавленную поверхность; focus-visible — бирюзовый контур; disabled приглушает фактуру и блокирует нажатие; loading показывает индикатор и блокирует повторный вызов. `aria-pressed` задаёт состояние переключателя. Для микрофона/камеры дополнительно меняется знак, чтобы состояние различалось без цвета. Уменьшенная анимация и системный режим высокой контрастности поддерживаются.

## Подключение

Исходники: `frontend/src/app/shared/painted-controls/`. Изображения: `frontend/public/assets/painted-controls/`. Импортировать нужные standalone-компоненты из `index.ts` этой папки.

```html
<button kvaPainted (click)="join()">Присоединиться</button>
<button kvaPainted variant="secondary" [loading]="connecting()">
  Подключиться
</button>
<button kvaPainted iconOnly aria-label="Микрофон"
  [attr.aria-pressed]="micEnabled()" (click)="toggleMic()">
  <kva-painted-glyph [name]="micEnabled() ? 'mic' : 'micOff'" />
</button>
<kva-painted-art name="friends" [size]="96" alt="Друзья" />
```

`variant`: primary / secondary / danger / quiet / tab / menu. `size`: sm / md / lg. `disabled` и `loading` — boolean. `type` по умолчанию button; для отправки формы явно задавать submit. Подпись обязательна: видимый текст либо aria-label у кнопки только с иконкой. Glyph декоративный и скрыт от скринридера; название задаётся на кнопке. Art по умолчанию декоративный (alt пустой), информативному изображению нужен alt. Не объявлять реальный звонок подключённым только ради демонстрации.

`quiet`, `tab` и `menu` — спокойные поверхности для плотных панелей. Они поддерживают цветовые переменные `--kva-control-ink`, `--kva-control-surface`, `--kva-control-border`, `--kva-control-selected`, `--kva-control-disabled-ink`, `--kva-control-disabled-surface`; светлый пример есть в каталоге. Выбор задаёт вызывающий компонент через `aria-pressed`. Вариант tab — только внешний вид: пример использует группу кнопок; полноценные ARIA-вкладки требуют собственной клавиатурной логики. Ссылки остаются элементами `<a>`, не заменять их кнопками ради внешнего вида.

## Карта будущего подключения

`inventory.json` строится командой `node scripts/audit-ui-kit.cjs` и содержит файлы, строки, статические и динамические значки, кнопки, ссылки, SVG и список нативных брендовых ресурсов. Это статическая карта, а не гарантия просмотра всех состояний приложения. Политика замены и очередность — `migration.md`. Каталог сравнивает 55 старых знаков с новыми; служебные символы и динамические ссылки проверяются отдельно. Автоматическая замена рабочих экранов не выполняется.

CSS ограничен префиксом `kva-painted-`. Поверхность панели доступна классом `kva-painted-panel`; если на странице нет PaintedButtonComponent, подключить `painted-controls.css` явно. Растровая графика декоративна для кнопок: при её отсутствии остаются фон, текст и SVG. При экспорте для другого base URL заменить `/assets/painted-controls/` в CSS; у Art есть input basePath.

## Сборка и проверка

Из `frontend`:

```text
node scripts/prepare-painted-assets.cjs
node scripts/build-painted-kit.cjs
node scripts/check-painted-kit.cjs
```

Первый шаг нужен при изменении графики: требует оригиналы `artifacts/painted-controls-originals/*.png` и Chromium Playwright. Он нормализует прозрачные поля и размеры, не перерисовывает изображения. `generation.json` содержит происхождение и промпты. PNG-мастера сохраняются отдельно от оптимизированных WebP; их не загружать вместе с обычной страницей.

Второй шаг создаёт переносимый `artifacts/painted-controls/index.html`, который открывается напрямую с диска, SVG, CSS, компоненты и изображения. Каталог включает Angular compiler только для автономного демонстрационного bundle; библиотека компонентов его не импортирует. Production-приложение собирает компоненты стандартным Angular builder.

Третий шаг проверяет реальные компоненты: Enter/Space, блокировку disabled/loading, переключатель, отсутствие изменения размера при загрузке, типы кнопок в форме, ширины 320/393/1024/1440, reduced-motion, forced-colors и клавиатурный фокус. Сохраняет снимки и verification.json. Дополнительно просмотреть снимки, края на светлом фоне, переносы и сравнение с эталоном. Успешная сборка не доказывает визуального совпадения.

Графика восстановлена по эталону отдельными изображениями; это не побитовое извлечение исходных слоёв. Для будущих изменений сначала переиспользовать готовые элементы. Генерировать заново только недостающий или явно изменяемый элемент, сохраняя этот reference.png.
