# Парящая навигация

Выбранный вариант — `reference.png`. Поверхность `master.png` создана встроенным ImageGen по этому референсу; точный промпт сохранён в `generation.json`.

Экспорт: из `frontend` выполнить `node scripts/prepare-floating-navigation.cjs`. Результат — `public/assets/enamel-navigation/floating-panel.webp`, 512×512 с прозрачными краями. CSS использует девять частей изображения (`border-image: 9% fill / 16px`): углы и ободок сохраняют размер при вертикальном и горизонтальном масштабировании. CSS не обрезает рисованный край.

Общий материал — `shared/_floating-enamel.scss`. На ПК колонка остаётся в прежней сетке 92 px, панель отступает на 6 px от края окна и на 8 px от соседней колонки. Прежняя прямая граница заменена просветом и тенью. Содержимое прокручивается внутри поверхности; фокус кнопок доступен на низких экранах.

На мобильных поверхность применена к существующей нижней навигации. Сохранены пять кнопок с областью нажатия не меньше 44×44 px, обычный поток компоновки, поведение меню и скрытие при открытой клавиатуре. Безопасные отступы устройства резервирует существующая оболочка. Эмаль остаётся тёмной в светлой теме, подписи получают локальные контрастные цвета. В forced-colors используется системная поверхность без текстуры.

Проверки: `navigation-art.spec.ts`, `shared-navigation.spec.ts`, `platform-navigation.spec.ts`; снимки 320/393/1024/1440 px, светлая палитра и низкое окно 1024×600. Снимки создаются в `frontend/test-results/`.
