# Фэнтези

Коллекция из десяти изображений, предоставленных владельцем. Оригиналы сохранены в `Backups/fantasy-originals`, их SHA-256 — в `collection.json`. WebP 512 × 512 подготовлены стандартным обработчиком загрузки; кеш создаёт превью 256 × 256. Обложка — Лунная эльфийка.

| Предмет | Редкость | Кристаллы |
|---|---|---:|
| Лунная эльфийка | Эпический | 450 |
| Серебряный страж | Редкий | 300 |
| Орк-воевода | Редкий | 250 |
| Шаманка духов | Эпический | 500 |
| Лесной тролль | Необычный | 150 |
| Гоблин-изобретатель | Редкий | 250 |
| Рунный кузнец | Необычный | 200 |
| Кристальная фея | Эпический | 450 |
| Владычица кровавой луны | Легендарный | 750 |
| Король-лич | Легендарный | 800 |

Импорт из backend: `PYTHONPATH=. .venv/bin/python scripts/import_collection.py --manifest catalog/fantasy/collection.json --apply`. Без `--apply` — только проверка. Постоянные ID защищают от дубликатов; существующие предметы и настройки не перезаписываются.
