# Средиземье

Десять изображений предоставлены владельцем проекта. Оригиналы сохранены отдельно в `Backups/middle-earth-originals`; их SHA-256 записаны в `collection.json`.

WebP 512 × 512 подготовлены стандартным обработчиком загрузки проекта, без генерации новых изображений. Превью 256 × 256 создаются существующим кешем. Обложка подборки — Гэндальф; оформление использует текущую тему магазина.

| Предмет | Редкость | Кристаллы |
|---|---|---:|
| Орк Мордора | Необычный | 150 |
| Голлум | Редкий | 250 |
| Фродо | Редкий | 250 |
| Гимли | Редкий | 300 |
| Арагорн | Эпический | 450 |
| Арвен | Эпический | 450 |
| Древобород | Эпический | 500 |
| Назгул | Легендарный | 700 |
| Галадриэль | Легендарный | 750 |
| Гэндальф | Легендарный | 800 |

Из каталога backend: `PYTHONPATH=. .venv/bin/python scripts/import_middle_earth.py --apply`.
Без `--apply` выполняется только валидация. Нужны настроенные БД и хранилище приложения.
Идентификаторы постоянные; повторный импорт сохраняет настройки существующих предметов и подборки. Новые предложения публикуются одной транзакцией, не меняя другие товары, балансы или экземпляры.

В изолированной базе проверены повторный импорт, десять изображений и цен, редкости, состав подборки, покупка и применение Гэндальфа. Код сайта и схема БД для этой публикации не изменяются.
